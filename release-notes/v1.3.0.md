## Axon Servo Programmer 1.3.0 (pre-release)

### Performance
- **Much lower CPU, GPU and memory use.** Theme backgrounds are now drawn once instead of being animated and re-blurred every frame. When idle, the app now redraws **0 times per second** (1.2.0 redrew constantly in the Midnight, Aurora, Sunset and Liquid Glass themes).
- Liquid Glass uses native macOS blur instead of software blur.
- Spellchecker and unused Chromium services switched off to save memory.
- Servo checks slow down while the app is in the background, and speed up again when you switch back.
- Faster, snappier buttons and less work while dragging sliders.
- The activity log keeps fewer old lines on screen (full history stays saved).

### Fixes
- "Clear Cache" and other buttons no longer wrap onto two lines.
- Midnight theme panels are easier to read.

### Releases
- New versions are now built on a real Mac by GitHub Actions and published automatically, properly signed, as a smaller DMG.

### Install
Drag the app into Applications. The first time, either run this in Terminal:

    xattr -cr "/Applications/Axon Servo Programmer.app" && codesign --force --deep --sign - "/Applications/Axon Servo Programmer.app"

or open it and click **Open Anyway** in System Settings → Privacy & Security.

Already on 1.2.0? Open **Settings → Updates** to update in-app.

Requires the Axon Servo Programmer (USB) and an Apple Silicon Mac.

⚠️ Pre-release, use at your own risk. Unofficial, not affiliated with Axon. Check servo values after writing and keep the Windows software as a backup.

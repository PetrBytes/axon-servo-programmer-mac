## Axon Servo Programmer 1.4.2 (pre-release)

### Fix: updates failing with ENOTEMPTY
Downloading an update could fail with *“ENOTEMPTY: directory not empty, rmdir …/axon-programmer-update/staged/…”*. When the app opened, it started deleting the previous update's leftover files, and a few seconds later the update download tried to delete the same folder. The two clashed.

- Each download now goes into its own new folder, so nothing has to be deleted before downloading.
- Old update files are cleared in the background, never stop a download, and are retried next launch if macOS is still holding them.
- **Clear Cache** no longer deletes an update that's downloading or ready to install.
- Errors now say what failed (**Download failed**, **Couldn't install**) instead of always “Couldn't check”, and Try Again retries that step.

### Updating from 1.4.0 or 1.4.1
Those versions still have the old download code. If an update fails with ENOTEMPTY, press **Try Again** once the app has been open for a few seconds; it should then download normally.

### Install
New install: drag the app into Applications, then the first time either run

    xattr -cr "/Applications/Axon Servo Programmer.app" && codesign --force --deep --sign - "/Applications/Axon Servo Programmer.app"

or click **Open Anyway** in System Settings → Privacy & Security.

Requires the Axon Servo Programmer (USB) and an Apple Silicon Mac.

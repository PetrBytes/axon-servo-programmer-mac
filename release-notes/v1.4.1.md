## Axon Servo Programmer 1.4.1 (pre-release)

Checked side by side with Axon's Windows software (v1.0.5) on a real Axon MINI (AAS) and Axon MAX (UPL). Every setting and value matched. This release fixes the small differences that check found.

### Safety
- **Default (Factory) is now disabled for UPL servos** (such as the original Axon MAX). The Windows software greys this button out for them too. The app also refuses the reset at the protocol level, so no factory command is ever sent to a UPL servo.

### Matches the Windows software more closely
- **ProPTL is shown in seconds** next to the raw value (30 = 3.0 s), like the Windows UPL page.
- **Over Load Protection times are rounded to 0.1 s** (e.g. 8.2 s instead of 8.16 s). Untouched levels are still written back byte-for-byte, and older profiles are snapped to the new display when opened.
- **Lose PPM Protection** moved to the Power card.
- **PPM Range, Narrow Band and SANWA SSR** moved into a collapsed *Advanced signal settings* section, because the Windows software doesn't show them for these servos. It opens automatically if one of them changes, for example from a profile.

### Install
Already on 1.2.0 or later? Open **Settings → Updates**.
New install: drag the app into Applications, then the first time either run

    xattr -cr "/Applications/Axon Servo Programmer.app" && codesign --force --deep --sign - "/Applications/Axon Servo Programmer.app"

or click **Open Anyway** in System Settings → Privacy & Security.

Requires the Axon Servo Programmer (USB) and an Apple Silicon Mac.

⚠️ Pre-release, use at your own risk. Unofficial, not affiliated with Axon. Check servo values after writing and keep the Windows software as a backup.
